# Stitch UI Sync Skill

Use this skill when developing or styling UI components for FleetOS:
1. Reference `docs/DESIGN.md` for official tokens, colors, elevation, and component dimensions.
2. In Cockpit views (Mobile Driver PWA):
   - Maintain minimum 56px–60px touch height for all clickable targets.
   - Ground canvas: `#090D16` / `#0F172A`.
   - Structural borders: `#1E293B` (or `#334155` for high-elevation modals).
   - Emerald Telemetry `#10B981` for active/synced state.
   - High-Vis Amber `#F59E0B` for offline/caution state.
   - Use `JetBrains Mono` for odometer, currency (₹), and telemetry data.
   - Use `Space Grotesk` for headlines.
   - Use `Plus Jakarta Sans` for body text and labels.
