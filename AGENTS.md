# FleetOS Architectural & Coding Invariants

## 1. Offline-First Contract (Mobile Driver PWA)
- **Local Write First:** Every driver action (Trip Start, Fuel Receipt, Trip End) MUST commit to `Dexie.js` (`IndexedDB`) before any network dispatch is attempted.
- **Persistent Status Badging:** The UI must reflect connection and sync state continuously:
  - `Online • All Synced` (Pulsing Emerald `#10B981`)
  - `Offline • X Records Queued` (High-Vis Amber `#F59E0B`)
- **Camera Capture & Compression:** Diesel bill photos must use native camera capture (`accept="image/*" capture="environment"`). Images MUST be compressed client-side to `<= 250 KB` WebP/JPEG using `browser-image-compression` before being saved to IndexedDB or queued for sync.

## 2. Idempotent Offline Sync Protocol (Backend API)
- **Client Identifiers:** Every mutation record generated by a client must include a client-generated `UUIDv4` as `client_event_id` and an ISO-8601 `recorded_at` timestamp.
- **Database Uniqueness Constraint:** The backend database schema MUST enforce a `UNIQUE` constraint on `client_event_id`.
- **Deduplication Invariant:** If `POST /api/v1/sync/batch` receives an already processed `client_event_id`, it must acknowledge it with `HTTP 200/201 (status: "deduplicated")` without re-creating records or re-calculating financial/KM totals.

## 3. Core Domain & Validation Invariants
- **Odometer Sequence:** A trip's `end_km` MUST strictly exceed `start_km` (`end_km > start_km`). Any payload violating this constraint must be rejected with validation errors.
- **P&L Ledger Formulas:**
  - `total_km = end_km - start_km`
  - `mileage_kmpl = total_km / total_liters` (guard against `total_liters == 0`)
  - `net_profit = cash_received_inr - (diesel_total + tolls_and_extras_inr)`
- **Compliance Warning Thresholds:**
  - Green: `> 30 days` until expiry
  - Amber: `<= 30 days` and `>= 0 days` until expiry
  - Red: `< 0 days` (Expired)
- **Google Calendar Color Contract:**
  - 🟢 Green (`colorId: "10"`): Confirmed Trip
  - 🟡 Yellow (`colorId: "5"`): Pending Quote / Inquiry
  - 🔴 Red (`colorId: "11"`): Scheduled Maintenance / FC Renewal

## 4. UI Design System Invariant (Cockpit Slate Industrial)
- **Design Tokens:** Follow `docs/DESIGN.md` extracted from Google Stitch.
- **Dark Cockpit Ground:** Deep slate background `#090D16` and elevated card container `#0F172A` with structured border `#1E293B`.
- **Touch Target Dimensions:** All primary interactive controls for mobile driver screens MUST maintain at least `56px` to `60px` touch targets with `scale(0.98)` tactile downscaling and haptic feedback (`navigator.vibrate([40])`).
- **Typography:**
  - Headlines: `Space Grotesk`
  - Body & Labels: `Plus Jakarta Sans`
  - Currency, Telemetry & Odometers: `JetBrains Mono`

## 5. Security, Cloud Storage & Auth Invariants
- **Admin JWT Protection:** All `/admin` endpoints (`/trips`, `/fuel`, `/compliance`, and admin `/calendar`) require a valid HS256 JWT issued by `POST /api/v1/auth/login` with Argon2 password verification.
- **Driver QR Secret Authentication:** Driver-facing endpoints (`/sync/batch`, `/uploads/receipt`, `/calendar/today`) MUST validate the `X-Driver-Key` header against `DRIVER_QR_SECRET` using `secrets.compare_digest`.
- **Upload Hardening:** Receipts must never exceed `1 MB` and must have verified image magic bytes (`JPEG`, `PNG`, `WebP`). Renamed to `<uuid4>.<ext>` to avoid path traversal.
- **S3-Compatible Cloud Storage:** Production receipt uploads store to S3-compatible providers (Supabase Storage, Cloudflare R2, AWS S3) via boto3 (`STORAGE_BACKEND="s3"`, with `"r2"` supported as an alias) with fallback to local disk storage in development.
- **Neon PostgreSQL Compatibility:** Database engine must automatically strip `sslmode=require` query parameters and pass `connect_args={"ssl": True}` to `create_async_engine` for non-localhost PostgreSQL hosts.

## 6. Bilingual & Voice Input Invariants (Mobile Driver Cockpit)
- **Bilingual Context:** All driver-facing UI copy MUST support seamless English (`en`) and Tamil (`ta`) switching via `LanguageProvider`. Language selection persists across reloads via `localStorage` (`fleetos_lang`, default `"en"`).
- **Speech Recognition (`VoiceInputField`):** Speech-to-text uses native Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`) with dynamic locale binding (`ta-IN` for Tamil, `en-IN` for English).
- **Spoken Unit Stripping:** All numeric fields (`start_km`, `end_km`, `amount_inr`, `liters`, `cash_received_inr`, `tolls_and_extras_inr`) pass through `parseSpokenNumber()`, cleanly stripping currency words (`"rupees"`, `"rs"`, `"ரூபாய்"`) and unit tokens (`"km"`, `"கிலோமீட்டர்"`, `"liters"`, `"லிட்டர்"`).
- **Offline Driver Slot Caching:** Driver calendar slots (`GET /api/v1/calendar/driver-slots`) must be cached into Dexie (`calendarSlots` table) on online transitions, allowing instant offline slot selection on rural or remote routes.
